2. ESTRUTURA CRIADA NO BANCO
--------------------------------------------------------------------
Tabela  public.installations
  - id (uuid, PK), installation_id (texto unico), name (texto),
    status (pendente | autorizada | bloqueada), created_at, updated_at
  - RLS habilitada com politica de negacao total para os papeis do
    aplicativo (anon / authenticated)
  - Privilegios diretos de SELECT/INSERT/UPDATE/DELETE revogados para
    os papeis do aplicativo

Funcao  public.monit_installation_access(p_installation_id, p_name)
  - SECURITY DEFINER, SET search_path = public
  - valida o formato do identificador (UUID)
  - cadastra a instalacao como "pendente" na primeira execucao, sem
    duplicar registros
  - retorna SOMENTE name e status da propria instalacao consultada
  - nao permite ao aplicativo criar, alterar ou apagar status
  - somente EXECUTE concedido aos papeis do aplicativo

4. TESTES EXECUTADOS E RESULTADOS
--------------------------------------------------------------------
4.1 SEGURANCA (chamadas reais com a chave publica do aplicativo)
  SELECT direto na tabela ................ NEGADO (permission denied)
  INSERT direto .......................... NEGADO (permission denied)
  UPDATE de status ....................... NEGADO (permission denied)
  DELETE ................................. NEGADO (permission denied)
  RPC com identificador invalido ......... REJEITADO pela funcao
  RPC da instalacao A ................ retorna somente A (pendente)
  RPC da instalacao B ................ retorna somente B (pendente)
  Conclusao: o aplicativo nao consegue listar, criar, alterar nem
  apagar registros; nao ha como enumerar instalacoes. O unico acesso e
  a consulta do proprio identificador aleatorio.

4.2 ESTADOS DE ACESSO (aplicativo real, no navegador)
  pendente ...... acesso negado, mensagem "Esta instalacao ainda nao
                  foi autorizada. Entre em contato com o administrador."
  autorizada .... tela de login liberada
  bloqueada ..... acesso negado, mensagem "Esta instalacao esta
                  bloqueada. Entre em contato com o administrador."
  desbloqueio remoto (bloqueada -> autorizada) ..... acesso liberado
                  novamente apos nova consulta

4.3 OFFLINE / FALHA DE COMUNICACAO
  Instalacao autorizada + rede cortada ... acesso mantido pelo cache
                  local (nao caiu para bloqueada)
  Primeira execucao sem comunicacao e sem estado anterior ... negado
  Erros de rede, timeout, DNS e 5xx sao tratados como "sem
  comunicacao" no codigo de consulta remota.

4.4 PERSISTENCIA DO INSTALLATION ID
  Identificador gerado uma unica vez e mantido no armazenamento local
  (verificado no aplicativo em execucao: mesmo identificador em
  recarregamentos sucessivos). Nenhuma alteracao no gerador original.

5. PENDENCIA CONHECIDA (NAO CONCLUIDO)
--------------------------------------------------------------------
5.1 Geracao do instalador Windows (npm run dist) NAO foi concluida
    neste ambiente. A compilacao do aplicativo funciona, mas o
    empacotamento/assinatura para Windows falha porque o ambiente de
    build e Linux e a ferramenta de assinatura nao pode ser executada
    (ERR_ELECTRON_BUILDER_CANNOT_EXECUTE na etapa de assinatura).
    Isso e limitacao do ambiente, nao do codigo. O instalador deve ser
    gerado em uma maquina Windows.

5.2 Avisos do verificador de seguranca do banco:
    "Public/Signed-In Users Can Execute SECURITY DEFINER Function".
    Sao esperados e aceitos por decisao de arquitetura: o requisito
    proibe API intermediaria, portanto o aplicativo precisa executar a
    funcao sem login. A funcao foi endurecida (search_path fixo,
    validacao de identificador, retorno apenas da propria linha,
    nenhuma escrita de status pelo cliente, nenhum dado sensivel
    exposto).

6. CONCLUSAO

4.1 a 4.5. A unica etapa nao concluida e a geracao do instalador
